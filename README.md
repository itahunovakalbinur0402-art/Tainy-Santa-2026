# Тайный Санта 2026 — версия для Render + PostgreSQL

## Структура
- `server.js` — Express API и подключение к PostgreSQL
- `public/` — интерфейс сайта
- `package.json` — зависимости

## Перед публикацией
1. Создайте PostgreSQL базу данных (например, Neon).
2. Создайте Web Service в Render, подключив GitHub-репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. В Environment Variables добавьте:
   - `DATABASE_URL` — строка подключения PostgreSQL
   - `SESSION_SECRET` — длинная случайная секретная строка
   - `BASE_URL` — публичный URL сервиса Render, например `https://имя.onrender.com`

Таблицы приложения и таблица сессий создаются автоматически при запуске.
База данных должна разрешать SSL-подключение. Не публикуйте `DATABASE_URL` и `SESSION_SECRET` в GitHub.

## Важно
Это подготовленный исходный проект, а не уже опубликованный сайт. После загрузки в хостинг нужно проверить `/api/health`, регистрацию, вход, приглашение, вишлист и жеребьёвку. Бесплатные тарифы хостинга могут засыпать или иметь ограничения; проверьте актуальные условия перед созданием сервиса.
